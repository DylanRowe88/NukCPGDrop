Key differences:
1. No onboard USB-UART bridge -- Type-C only supports USB-serial-JTAG (built into ESP32-S3). Windows 10+ only.
2. Display RST shared with ESP32 EN -- No dedicated reset pin for display (uses ESP32 system reset).
3. I2C bus shared between touch controller (FT6336G) and audio codec (ES8311) on GPIO 15/16.
4. SDMMC uses non-default pins -- 38, 40, 39, 41, 48, 47 instead of the typical 14,15,2,4,12,13.
5. GPIO 46 as DC -- Unusual pin, only available on ESP32-S3 (high-number GPIO).
6. GPIO 45 as BL -- Again, high-number S3-specific GPIO.
7. I2S pins (4,5,6,7,8) are dedicated audio pins, not found on a basic DevKitC.
1.8 POWER/VOLTAGE
- Input: 5V via USB Type-C
- Battery: Measured via ADC (ADC1_CH8) with a 2:1 voltage divider (raw_mV * 2 = battery_mV)
- Voltage range: ~2500mV to 4200mV (LiPo battery range)
- Battery level calculation: level = (voltage_mV - 2500) / 17 (0-100%)
- Regulator: ME6217 LDO (datasheet present in DataSheet folder)
- Charger: TP4054 LiPo charger (datasheet present)
- Backlight: PWM on GPIO 45, 2000Hz, 8-bit resolution

KEY TAKEAWAYS
1. This is a complete ESP32-S3 development board with integrated 2.8" ILI9341 SPI display, FT6336G capacitive touch, ES8311 I2S audio codec with mic input, SD card slot, NeoPixel RGB LED strip (60 LEDs), LiPo battery charger, and USB Type-C.
2. Three programming frameworks supported: Arduino (via Arduino-ESP32), ESP-IDF v5.4.1, and MicroPython v1.25.0.
3. The pinout is radically different from standard DevKitC -- many high GPIOs (38-48) are used for SDMMC and other peripherals. GPIOs 1, 4-8, 10, 42, 45, 46 are all used for display/audio/NeoPixel functions not present on a basic DevKitC.
4. No external USB-UART chip -- relies entirely on ESP32-S3's built-in USB-serial-JTAG. Only works on Windows 10+.
5. Touch and audio codec share the same I2C bus (GPIO 15/16).
6. The display has no dedicated reset pin -- it is tied to the ESP32 EN line.

SUMMARY OF FLASHING PROCEDURE (reconstructed from data)
1. Enter download mode: Hold BOOT button, power on (or press RESET while holding BOOT), then release RESET then BOOT.
2. Open Flash Download Tool (flash_download_tool/) -- Espressif tool v3.9.9
3. Configure:
- Chip type: ESP32-S3
- Flash size: 16MB
- Flash mode: DIO (or QIO)
- Flash frequency: 80MHz
- Baud rate: 115200 (USB Serial/JTAG)
4. Load binaries:
- Bootloader (offset 0x0)
- Partition table (offset 0x8000)
- Application binary (offset 0x10000)
5. For pre-compiled demos (bin/LVGL/ or bin/xiaozhi/), load the .bin files at appropriate offsets
6. Start flashing
